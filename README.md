#  Expense Tracker

A simple and beginner-friendly **Expense Tracker** built using **Python**. This project helps users record their expenses and calculate the total amount spent.

## 📌 About the Project

The Expense Tracker is a console-based Python project created to practice fundamental Python programming concepts.
Users can enter their expenses, and the program stores the data in a list and calculates the total expense.

## ✨ Features

* ➕ Add multiple expenses
* 📝 Store expense details
* 💰 Calculate total expenses
* 📋 Display entered expenses
* 🔄 Use loops to handle multiple entries
* 🛑 Allow the user to stop adding expenses
* 🧮 Perform basic calculations

## ⚙️ How It Works

1. The program starts by creating an empty list to store expenses.
2. The user is asked to enter an expense with name ,then add the amount.
3. Each expense is added to the list using `append().
4. A loop allows the user to enter multiple expenses.
5. When the user finishes entering expenses, the program displays them.
6. A `for loop goes through the expense list and calculates the total.
7. Finally, the total amount spent is displayed.
